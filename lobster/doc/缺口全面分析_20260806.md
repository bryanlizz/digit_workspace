## 六、按端职责的缺口

### admin（平台总后台）— 缺口最大

当前页面：概览、计费、用户、权限（多为 stub）
缺失入口：模型路由/AI 网关、MCP Server 注册、Tool Runtime 治理、Connector Registry、平台审计、部署治理、系统设置

### enterprise（企业后台）— 缺口较大

当前页面：概览、员工、权限、Agent、凭证、知识
缺失入口：企业工具配置/Agent 授权、浏览器自动化环境、企业审计/审批流、Bad Case 管理、Agent Worker

### web（主产品端）— 相对完整

缺失：legacy 页面迁移提示、模型路由入口迁入 admin、人类接管入口产品化、任务结果详情页

### desktop（个人客户端）— 本次已补齐协作

本次新增：WarRoomChat + FileDropzone + 协作页面，从占位变为可用
仍缺失：真实接管体验（验证码/扫码/二次认证等本地入口）

## 八、建议优先级

### 第一批：安全地基（P0，~2 周）

1. tRPC auth guard 投入使用（`protectedProcedure` 替换 `publicProcedure`）
2. 多租户 `tenantId` 全链路注入（消除 `DEFAULT_TENANT_ID` 硬编码）
3. 动作级审批引擎

### 第二批：合规闭环（P0-P1，~3 周）

4. OAuth Token 自动刷新
5. 不可篡改审计存储（hash chain 写入 DB）
6. Bad Case 自动归因（AI 分析失败原因）
7. IMAP/SMTP 脱离 mock

### 第三批：完整交付（P1-P2，~4 周）

8. 浏览器录屏 + 审计报告导出
9. MCP 接入框架完善
10. Boss E2E 验证 + 接管后继续执行
11. web legacy 迁移提示
12. Agent 克隆
