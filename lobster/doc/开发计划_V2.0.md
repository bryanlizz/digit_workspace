## 一、当前状态评估

| 维度 | 完成度 | 说明 |

| 演示型驾驶舱 | ~80% | UI 完整，交互流畅 |

## 二、产品目标确认

| 项 | 值 |
|----|----|
| 产品形态 | 可商用 · 企业 Agent 操作平台 |
| 首批场景 | 招聘（猎聘/Boss）+ 销售（CRM/邮件） |
| 首批接入 | 飞书 + Boss + 邮件 + 短信 |

## 三、开发阶段规划

### 阶段 0：补全现有缺口（P0）

**目标**：修复当前系统的明显缺陷，为后续扩展打基础

#### 0.1 持久化链路打通

| 任务 | 文件 | 优先级 |
|------|------|--------|
| 作战室聊天消息持久化 | `prisma/schema.prisma` 新增 `WarRoomMessage` 模型 | P0 |
| 作战室消息 API 接口 | `api/project/sendMessage`, `api/project/getMessages` | P0 |
| 详情面板记忆连接真实 API | `DetailPanel.tsx` 调用 `api.memory.search` | P1 |
| Bad Case 从驳回任务获取 | `evolution/index.tsx` 改为查询 `status: REJECTED` | P1 |
| 知识图谱数据源接入 | `agentRuntime.runTask` 后触发 `graphExtractor` | P1 |

#### 0.2 AI 执行链路打通

| 任务 | 文件 | 优先级 |
|------|------|--------|
| AI 网关集成到执行器 | `aiExecutor.ts` 调用 `aiGateway.getAvailableKey()` | P0 |
| 移除 Mock 强制模式 | `USE_MOCK` 改为读取配置 | P0 |
| 执行结果写回 Repository | `agentRuntime.ts` 通过 `taskRepo.update` 更新状态 | P0 |
| 执行结果写入记忆服务 | `memoryService.write()` 持久化执行结果 | P1 |

#### 0.3 UI 完善

| 任务 | 文件 | 优先级 |
|------|------|--------|
| 路演模式相机动画 | `TourMode.tsx` 集成 `CameraControls` | P2 |
| 项目参与者 JSON 兼容修复 | 前端适配 SQLite String 类型 | P1 |
| Loading/空状态补全 | 各列表页面 | P2 |

### 阶段 1：外部系统集成基础（P0）

**目标**：建立外部系统接入的核心基础设施

#### 1.1 Credential Vault

| 任务 | 说明 | 优先级 |
|------|------|--------|
| Vault 数据模型 | Prisma 新增 `Credential`, `OAuthToken` 模型 | P0 |
| Vault API | CRUD + 加密存储 + 自动刷新 | P0 |
| Token 刷新机制 | OAuth 令牌自动刷新逻辑 | P0 |
| 凭证与 Agent 绑定 | 凭证归属最近的自然人上司 | P0 |
| 凭证不可见性 | Agent API 不可获取明文凭证 | P0 |

#### 1.2 Tool Runtime 架构

| 任务 | 说明 | 优先级 |
|------|------|--------|
| Tool 定义规范 | 定义 `Tool` 接口结构 | P0 |
| Tool Registry | 工具注册与发现机制 | P0 |
| Tool Executor | 工具执行引擎 | P0 |
| Tool 审计钩子 | 每次调用记录审计日志 | P0 |

#### 1.3 Connector 基础框架

| 任务 | 说明 | 优先级 |
|------|------|--------|
| Connector 接口 | 定义 `Connector` 抽象 | P0 |
| HTTP Connector | 通用 HTTP 请求 connector | P0 |
| OAuth Connector | OAuth 2.0 授权流程 | P1 |

### 阶段 3：执行引擎升级（P0）

## 七、技术栈建议

| 层 | 技术选型 |
|----|----------|
| 工具运行时 | MCP (Model Context Protocol) |
| 凭证管理 | HashiCorp Vault（或自建） |
| 浏览器自动化 | Playwright |
| 企业集成 | 飞书开放平台 SDK |
| 任务队列 | BullMQ / Inngest |
| 审计存储 | append-only 日志 |
| 容器化 | Docker + Docker Compose |
| 私有化 | Kubernetes Helm Chart |

## 八、风险与注意事项

| 风险 | 缓解措施 |
|------|----------|
| Boss 平台封号 | IP 池 + 登录频率控制 + 人工接管 |
| 招聘合规风险 | 明确告知客户风险，企业自行承担 |
| OAuth 令牌失效 | 自动刷新 + 过期提醒 |
| 私有化部署复杂度 | 提供标准部署包 + 实施文档 |
| 执行超时/死循环 | 任务超时机制 + 最大步骤限制 |
